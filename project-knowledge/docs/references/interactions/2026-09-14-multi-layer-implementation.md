# 複数レイヤーと必須表示名の実装記録

利用者は複数レイヤーの仕様を検討し、個人用・チーム用・公開用の3レイヤーを代表的な構成とした。曖昧な更新先のAI選択では公開用を通常候補から外す必要があるため、`auto_select: false`を採用した。さらに、AIと利用者が安定してレイヤーを呼べるよう、機械識別子`id`を残したまま必須の表示名`name`を追加し、自然言語での明確な`name`または`id`指定は明示選択として扱うことを決めた。

実装差分では、設定パーサが任意数のレイヤー、必須`name`、`auto_select`、`write_target`との整合性を扱い、設定解決CLIが`id`、`name`、`auto_select`、`available`を返す。関連Skillは全レイヤー参照と単一レイヤー書込み、表示名による説明・選択の契約へ更新された。設定解決を`--write`で確認し、既定レイヤーが書込み可能であることを確認した。

利用者はテストとBenchmarkの詳細な変更・確認は公開後に作り直す可能性があるため、今回の重点ではないと示した。このため、本作業では設定解決の確認だけを行い、テストおよびBenchmarkの包括的な再検証は未実施である。
