# 仕様相談用テキストの再生成方針

Project Knowledgeスキル群の現在の仕様と構成を、ChatGPTなど他のチャットへ相談できる一つのテキストにまとめる。
細部は省き、概要と大切な考え方へ絞る。

データフォーマット、特に独自メタデータの意味、バージョニングの仕様、`config.yml`で設定可能な内容は詳しく記載する。
具体的な現行バージョン番号は不要とする。
文書自体の最終更新日を記載する。

今後、スキルの仕様や構成が変わった場合は、同じ方針と重視ポイントで仕様相談用テキストを再作成できるようにする。
短い自然言語の指示だけで再生成できるよう、再生成方法と今回の指示内容をProject Knowledgeへ記録する。

「十四ポイント」という記載は「重視ポイント」の誤記である。
