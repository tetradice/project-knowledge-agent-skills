# 標準Knowledge PolicyをSkillから参照する方針

`project-knowledge/knowledge-policy.md`の本文には、Agent Skill `project-knowledge`の標準Policyに従う宣言と、Skillに同梱された標準Policyへの参照情報を記載する。

標準PolicyはSkillの`references/`に配置し、外部URLを参照しない。

ユーザーからプロジェクト固有の収集方針が提示された場合は、その方針を本文へ記載し、指定されていない部分にはSkill同梱の標準Policyを適用する。

形式版とSkill版は変更しない。validatorは新しい本文構造を必須化せず、自由形式本文を引き続き許容する。
