# init / updateのファイル変更報告の方針

利用者は、`init`と`update`の完了後に、追加・更新したファイル数を分類して出力するよう求めた。

分類規則は将来ほかの機能でも再利用できるよう、一つの独立したMarkdownファイルへ置く。利用者向けの表示件数と合計件数には`Support`および`Internal`を含めず、これらの分類の件数は表示しない。
