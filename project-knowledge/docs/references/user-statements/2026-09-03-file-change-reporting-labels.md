# ファイル変更報告の表示名

利用者は、`init`と`update`のファイル変更報告で分類名を分かりやすい日本語で出力するよう求めた。

分類の内部値は維持し、利用者向け表示では`Knowledge`を「ナレッジ文書」、`Provenance`を「根拠資料」とする。内訳も日本語で表示し、`derived`だけは「分析の結果」とする。
