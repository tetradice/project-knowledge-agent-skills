# 外部レイヤーパスの許可

利用者は、`layers[].path`でプロジェクト外へ出る`..`、絶対パス、symlink／junction、UNC経由を許可し、外部レイヤーも`read-write`に従って初期化、更新、分割、復旧の対象にするよう求めた。`version: "1.0"`は変更しない。

利用者は、環境変数、URL、`~`、globは引き続き拒否することを求めた。設定ファイル自身のsymlink禁止、実体パスの同一・親子重複禁止、登録済みレイヤー内だけへ書き込む境界を維持する。

候補、バックアップ、指紋はプロジェクト内の作業領域に保存し、プロジェクト内レイヤーだけをプロジェクトの`.gitignore`管理ブロックへ出力することを求めた。外部レイヤーでは無効な相対ignoreを出力せず、外部レイヤー自身の`.gitignore`を利用する。パス表示はプロジェクト内では相対、外部では解決済み絶対パスに統一する。
