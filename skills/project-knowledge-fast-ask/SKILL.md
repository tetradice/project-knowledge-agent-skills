name: project-knowledge-fast-ask
description: project-knowledge/ の情報だけを使い、ユーザーの質問に高速に回答する。ユーザーが「プロジェクトナレッジの情報のみをもとに回答してください」など情報源を明示的に限定した場合、または `$project-knowledge-fast-ask` を手動で呼び出した場合のみ使用する。通常の質問、最新性の検証、実装との比較、ナレッジの更新には使用しない。

# 基本

回答は `project-knowledge/` 内の情報だけで構成する。

ソースコード、Git履歴、設定、外部環境、Web、一般知識を回答の根拠にしない。
利用可能な会話またはセッションのメモリは、古さを検知する場合だけ使用する。
メモリの内容を回答や出典へ加えない。

# 読み込み

1. リポジトリルートの `project-knowledge/index.md` を読む。
2. 索引の説明から質問に関係するナレッジファイルを特定する。
3. 特定したファイルだけを読む。
4. 質問に関係する未反映事項の有無を調べるため、`project-knowledge/pending.md` を読む。
5. 実際に読んだナレッジファイルのパスを記録する。

ナレッジ全体を無条件に読み込まない。
`project-knowledge/index.md` が存在しない場合は、他の情報源へフォールバックしない。

# 情報の扱い

- ナレッジに書かれていない事実、因果関係、結論を推測しない。
- 回答に必要な情報がない場合は、プロジェクトナレッジに回答材料がないと明記する。
- ナレッジ内に解消できない矛盾がある場合は、断定せず矛盾を示す。
- `pending.md` と他のナレッジが競合する場合は、未反映事項であることを明記し、`pending.md` の内容を優先する。
- 秘密情報または認証情報と判断できる値は引用せず、出力もしない。

# 古さの判定

次のいずれかに該当する場合だけ、古い可能性を警告する。

- 関連する `pending.md` に、他のナレッジより後に決まった未反映情報がある。
- 利用可能な会話またはセッションのメモリが、ナレッジの生成または検証後に生じた変更を明示している。
- ナレッジ自体に、廃止、旧仕様、非推奨などの記載がある。
- 関連ファイルが矛盾し、`generated`、`verified`、provenanceから古い側を特定できる。

経過日数、`verified` の欠落、すべての `verified.at` が `generated.at` より古いこと、`git_base_commit` の存在だけを警告理由にしない。

警告には次の文をそのまま使用する。

> 古い情報かもしれません。明示的に「最新のソースを確認してください」と指示してもらえれば、ソースと比較して確認します。

# 回答形式

回答は必ず次の順序で記述する。

1. 最初の文を `プロジェクトナレッジの情報によると、` で始める。
2. ナレッジに基づく回答、情報不足、または矛盾を簡潔に示す。
3. 古さの具体的な根拠がある場合だけ、指定の警告文を記載する。
4. `注: 実際のソースコードは確認していません。` と記載する。
5. 最終行に `出典: ` と書き、実際に読んだすべてのナレッジファイルを列挙する。

出典には `project-knowledge/` 内のファイルだけを記載する。
`index.md` が存在しない場合は、最終行を `出典: なし（project-knowledge/index.md が見つかりません）` とする。

出力例:

```md
プロジェクトナレッジの情報によると、<回答>

注: 実際のソースコードは確認していません。

出典: `project-knowledge/index.md`, `project-knowledge/<関連ファイル>.md`, `project-knowledge/pending.md`
```
