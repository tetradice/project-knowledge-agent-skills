# Project Knowledge format 0.1

## Status

Legacy read-only compatibility。明示的なmanifestを持たない。

## Detection

`project-knowledge/manifest.yml`が存在せず、次の既知構造をすべて持つ場合だけ0.1と判定する。

- `docs/index.md`
- `docs/log.md`
- `config.yml`
- `state.yml`

任意の未知ディレクトリを0.1とみなさない。

## Main characteristics

- Raw Reference保存先は`docs/references/captures/`と`docs/references/memos/`。
- `pk_source_kind`、`pk_authority`、`pk_trust`を使用する場合がある。
- `state.yml`が曖昧な`version`を持つ。
- OKF予約ファイルやConceptの`type`が一貫していない場合がある。
- `category`と`derivation`は要求しない。

## Compatible skills

Project Knowledge関連Skill 0.2.0はread-onlyで読み取れる。書込みは0.2 migration後に行う。
