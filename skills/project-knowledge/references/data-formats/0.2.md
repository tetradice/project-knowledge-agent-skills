# Project Knowledge format 0.2

## Manifest

```yaml
format: project-knowledge
format_version: "0.2"
```

`format_version`は文字列としてquoteする。

## Changes from 0.1

- OKF v0.2のreserved file、`type`、`sources`、actor規約へ整合。
- 通常Conceptへ`category`と`derivation`を追加。
- sourceへ`pk_source_type`を追加。
- `captures/`を`user-statements/`、`memos/`を`interactions/`へ改名。
- `pk_source_kind`を`pk_source_type`へ改名し、`pk_authority`と`pk_trust`を廃止。
- `memo.require_approval_for_trust`を廃止。
- `state.yml`の`version`を`state_schema_version`へ改名。
- 新規Conceptでは汎用`version`を生成しない。既存値はopaqueなlegacy extensionとして読める。

## Required fields

通常Conceptは`type`、`category`、`derivation`を持つ。Raw Referenceは`type: Reference`と`pk_source_type`を持ち、分類対象外とする。`sources`の各sourceは`resource`と`pk_source_type`を持つ。

0.1から移行した分類不明のConceptだけは`pk_legacy_unclassified: true`で欠落を明示できる。新規生成では認めない。

## Compatible skills

- `project-knowledge` 0.3.0
- `project-knowledge-fast-ask` 0.2.0
- `project-knowledge-publish` 0.2.0
- `project-knowledge-verify` 0.2.0
- `project-knowledge-audit` 0.2.0
