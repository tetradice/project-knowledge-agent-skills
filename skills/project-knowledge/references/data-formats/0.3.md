# Project Knowledge format 0.3

## Manifest

```yaml
format: project-knowledge
format_version: "0.3"
```

`format_version`は文字列としてquoteする。

## Changes from 0.2

- OKF標準外のProject Knowledge独自frontmatter fieldへ`pk_` prefixを付ける。
- `category`を`pk_category`へ改名する。
- `derivation`を`pk_derivation`へ改名する。
- OKF fieldの`type`、`status`、`sources`、`generated`、`verified`、`stale`、`stale_after`は変更しない。
- OKF frontmatterではない`manifest.yml`、`state.yml`、`config.yml`の管理キーは変更しない。

## Required fields

通常Conceptは`type`、`pk_category`、`pk_derivation`を持つ。Raw Referenceは`type: Reference`と`pk_source_type`を持ち、分類対象外とする。`sources`の各sourceは`resource`と`pk_source_type`を持つ。

0.1から移行した分類不明のConceptだけは`pk_legacy_unclassified: true`で欠落を明示できる。新規生成では認めない。

## Compatible skills

- `project-knowledge-fast-ask` 0.3.0
- `project-knowledge-publish` 0.3.0
- `project-knowledge-verify` 0.3.0
