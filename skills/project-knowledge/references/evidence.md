# 情報源と調査

## 主張ごとの authority

情報源全体に固定の優先順位を付けない。
まず主張が表す情報の種類を分類し、その主張について authority を持つ情報源を判断する。

- 現在の実装状態: 現在のコードと設定
- 要件、業務ルール: 明示された `references/requirements/` などの trusted raw source
- 確定済み設計判断: `references/decisions/` などの trusted raw source
- 現在の外部状態: アクセス可能な実環境
- 変更の経緯と基準: Git の状態、diff、log
- 正式な情報源へ未統合で、後から復元できない情報: `project-knowledge/pending.md`

ディレクトリ名だけで機械的に分類せず、資料の内容と主張を確認する。
たとえば、references に記録された外部環境の過去状態より、アクセス可能な実環境を現在値の authority とする。
会話履歴は補助情報とし、安定した情報源から復元できる主張の正本にはしない。

情報源が競合する場合は、次の順序で扱う。

1. 各情報が要件、現在実装、設計判断、現在の外部状態、その他のどれを表すか判断する。
2. その主張について authority を持つ情報源を判断する。
3. authority の対象が異なる場合は矛盾として一方を消さず、「要件と現在実装の差異」などとして両方を保持する。
4. 同じ authority の情報が競合し、根拠から解決できない場合は推測で選ばず報告する。

## Git 状態

`init` または `update` でファイルを変更する前に、次を確認する。

1. bundle を含む Git リポジトリのルートを特定する。
2. `git rev-parse HEAD` で完全長 40 文字の SHA を取得する。
3. 作業ツリーが dirty か確認する。

Git 管理外や初回コミット前で SHA を取得できない場合は、ファイルを変更せず中断する。作業ツリーが dirty でも処理は続け、完了時にその事実を報告する。

`check` では Git 履歴を利用できなくても検証を続ける。利用できなかった理由を完了時に報告する。

## 調査範囲

1. `project-knowledge/index.md` を読む。
2. ユーザー依頼から関連するコンセプトを特定する。
3. 対象コンセプトを読む。
4. 関連コンセプトの `sources` と `resource` を確認する。
5. `sources` に trusted raw source があれば、関連する資料だけを読む。
6. ファイル名、ディレクトリ構造、ユーザー依頼、対象コンセプトから未登録の関連資料が合理的に推測できる場合だけ、追加の trusted raw source を絞り込んで調査する。
7. `git_base_commit` が有効な場合は、そこから現在の `HEAD` までの差分を調査範囲の手掛かりにする。
8. 関連するコードと設定だけを調査する。
9. 必要な場合だけ外部環境を確認する。
10. 試行錯誤、一時状態、revert 済みの状態を無視する。
11. 各情報源が表す最終的な状態、要件、設計判断を対象とする。

`git_base_commit` からの差分だけを正本にしない。現在のコード、設定、`sources` も確認する。コミットが存在しない場合や履歴を辿れない場合は、その事実を報告して通常の調査を続ける。

ナレッジ全体や `project-knowledge/references/` 全体を毎回無条件に読み直さない。
trusted raw source は `.md` に限定せず、エージェントが安全にテキストとして解釈できる資料を対象とする。
秘密情報をナレッジや報告へ転記しない。

## trusted raw sources の保護

利用先プロジェクトの `project-knowledge/references/` は人間管理の読み取り専用入力として扱う。
通常の `init`、`check`、`update` では、内容の変更、削除、整形、Markdown への変換、改名、移動を行わない。
`init` の実行前から存在する場合も保持し、関連資料を初期構築の情報源として利用する。
ユーザーが資料自体の変更を明示した場合は、通常 operation の責務と分けて扱う。

## 外部環境

Firebase、AWS などの外部環境は、必要かつアクセスできる場合だけ確認する。

確認できない情報は推測しない。既存値を無条件に正しいとみなさず、確認できなかったことを報告する。
