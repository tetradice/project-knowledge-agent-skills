# update

## 調査

ユーザーが更新を明示した場合だけ実行する。
`evidence.md` に従い、関連するコンセプトと情報源だけを調査する。

## 更新

- 影響するファイルだけを更新する。
- 現在状態に関する古い記述を更新する。
- 要件、設計判断、現在の実装、現在の外部状態を区別し、不一致を消さない。
- 解決できない競合を推測で更新しない。
- 不要な記述を削除し、作業経緯や変更履歴を残さない。
- 概念の追加、削除、改名時だけ `index.md` を変更する。
- `metadata.md` に従って、変更したコンセプトの provenance を更新する。

`pending.md` の関連項目を確認し、正式なナレッジへ統合した項目と不要になった項目を削除する。
未解決項目だけを残し、`project-knowledge/references/` へ移動しない。

## 完了確認

- 更新内容が調査した現在状態と一致する。
- 根拠のない推測やrevert済みの状態を含まない。
- `sources`、`generated`、`verified`、`git_base_commit` が `metadata.md` に従う。
- `index.md` の frontmatter が `okf_version` だけである。
- `pending.md` の関連項目を処理した。
- trusted raw sources を変更していない。
- 無関係なナレッジファイルを変更していない。

変更したファイル、解決できない競合、取得できなかった情報源、Git 履歴を利用できなかった理由、調査開始時の dirty 状態を必要に応じて報告する。
