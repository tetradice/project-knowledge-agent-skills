# Migration 0.1 to 0.2

```text
uv run skills/project-knowledge/scripts/migrate_project.py <project-root> [--target 0.2] [--check]
```

`<project-root>`は`project-knowledge/`を含むプロジェクトルート、またはKnowledgeルート自体を指定できる。

## Safety contract

1. formatを検出し、0.1以外、malformed manifest、未知形式、downgrade、版の飛び越しを拒否する。
2. 全変換と移動先の競合を事前検査する。
3. 同名・同一内容は統合し、同名・異内容が一つでもあれば一切変更しない。
4. `--check`は変更予定、競合、migration chainだけを報告する。
5. manifestは全変換とpost-checkに成功した後、最後に書く。

## Transformations

- `captures/` → `user-statements/`
- `memos/` → `interactions/`
- Markdownリンク、index、`sources[].resource`の旧パスを新パスへ更新
- `pk_source_kind` → `pk_source_type`
- `pk_authority`と`pk_trust`を削除
- `memo.require_approval_for_trust`を削除
- root/nested `index.md`と`log.md`をOKF reserved形式へ変換
- 通常Conceptへ`type`を補完
- `state.yml`の`version` → `state_schema_version`

既存Conceptの`category`と`derivation`は推測しない。欠落時は`pk_legacy_unclassified: true`を付け、次回更新の候補として残す。

全変換は再実行可能である。中断してmanifestが書かれていなければ、同じcommandを再実行できる。
