# Migration 0.2 to 0.3

形式0.2のBundleを形式0.3へ安全かつ冪等に移行する。

## 変換

- 通常Conceptの`category`を`pk_category`へ改名する。
- 通常Conceptの`derivation`を`pk_derivation`へ改名する。
- Raw Referenceに分類fieldが残っていれば除去する。
- `manifest.yml`の`format_version`を最後に`"0.3"`へ更新する。

OKF標準fieldと管理ファイルのキーは変更しない。適用前に全出力と競合を計算し、競合時は何も変更しない。`--check`では書き込まない。
