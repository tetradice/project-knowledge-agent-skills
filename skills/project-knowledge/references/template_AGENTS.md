# プロジェクトナレッジ

- プロジェクト情報は `project-knowledge/index.md` を起点に参照する。
- 現在性が必要な場合は、現在のコード、設定、外部状態と照合する。
- ナレッジだけを情報源として回答するよう明示された場合は、`$project-knowledge-fast-ask` を使用する。
- ナレッジの検証には `$project-knowledge check` を使用する。
- ナレッジの更新が明示された場合だけ `$project-knowledge update` を使用する。
- 通常の実装変更だけを理由にナレッジを更新しない。
- 秘密情報や `.env` の値をナレッジへ保存しない。
